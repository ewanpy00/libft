# Libft Test Suite

Полная система тестирования для всех функций библиотеки libft.

## Структура

- `test_runner.c` - Основной файл для запуска тестов
- `test_runner.h` - Заголовочный файл с объявлениями
- `test_all.c` - Файл, вызывающий все тесты
- `test_*.c` - Индивидуальные тестовые файлы для каждой функции
- `Makefile` - Файл для компиляции и запуска тестов

## Использование

### Компиляция и запуск всех тестов

```bash
cd tests
make test
# или просто
make
./test_runner
```

### Очистка

```bash
make clean      # Удалить объектные файлы
make fclean     # Удалить объектные файлы и исполняемый файл
```

## Типы тестов

### Функции с оригинальными версиями

Для функций, которые имеют аналоги в стандартной библиотеке (например, `strlen`, `atoi`, `strchr` и т.д.), тесты сравнивают результат вашей функции с оригинальной версией.

### Функции без оригинальных версий

Для функций, которые являются уникальными для libft (например, `strjoin`, `split`, `itoa` и т.д.), тесты проверяют результат на соответствие ожидаемым значениям.

## Покрытие тестами

Тесты включают:
- ✅ Базовые случаи использования
- ✅ Граничные случаи (edge cases)
- ✅ Пустые строки/нулевые указатели
- ✅ Специальные символы
- ✅ Большие значения
- ✅ Переполнения
- ✅ Случаи, которые могут вызвать краш программы (для проверки правильного поведения при ошибках)

## Функции

### Part 1
- `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, `ft_isprint`
- `ft_toupper`, `ft_tolower`
- `ft_strlen`, `ft_strchr`, `ft_strrchr`, `ft_strncmp`, `ft_strdup`, `ft_strnstr`
- `ft_memset`, `ft_bzero`, `ft_memcpy`, `ft_memmove`, `ft_memchr`, `ft_memcmp`, `ft_calloc`
- `ft_atoi`, `ft_strlcpy`, `ft_strlcat`

### Part 2
- `ft_substr`, `ft_strjoin`, `ft_strtrim`, `ft_split`
- `ft_itoa`
- `ft_strmapi`, `ft_striteri`
- `ft_putchar_fd`, `ft_putstr_fd`, `ft_putendl_fd`, `ft_putnbr_fd`

### Bonus (Linked Lists)
- `ft_lstnew`, `ft_lstadd_front`, `ft_lstadd_back`
- `ft_lstsize`, `ft_lstlast`
- `ft_lstdelone`, `ft_lstclear`
- `ft_lstiter`, `ft_lstmap`

## Примечания

- Некоторые тесты с NULL указателями могут вызывать краш (это ожидаемое поведение для проверки обработки ошибок)
- Тесты автоматически компилируют libft с bonus функциями
- Все временные файлы, созданные тестами (например, для `put*_fd` функций), автоматически удаляются
